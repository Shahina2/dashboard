# Кино-вечер

Дашборд для быстрого поиска сериалов, выбора случайного фильма и ведения списка «Посмотреть».

## Локальный запуск
1. Скачайте папку с проектом.
2. Откройте файл `index.html` в браузере или запустите через расширение Live Server в VS Code.

## Функции
- Поиск сериалов: получение данных из Cinemeta по названию.
- Случайный фильм: загрузка случайной карточки из каталога Cinemeta.
- Мой список: локальное сохранение фильмов в `localStorage` (добавление и удаление).

## Источники данных (API)
- [Cinemeta](https://v3-cinemeta.strem.io/) - ключевые поля: `name`, `description`, `releaseInfo`, `imdbRating`.

## Ограничения
- API не требуют ключей, но зависят от доступности сторонних сервисов.
- При ошибке сети виджет показывает сообщение и кнопку повторной загрузки.
- Данные о фильмах и сериалах могут быть неполными (например, отсутствовать описание или год).

    Результат: Создана функция `searchShows()`, которая использует `fetch`, `response.ok` и `try...catch` для отображения статуса.
